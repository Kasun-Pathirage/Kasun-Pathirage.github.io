Part 3 showed how complicated the noise of a single transistor gets. An op-amp contains many such devices, so modelling each one is impractical. This lecture introduces the standard op-amp noise model, made of the three equivalent input-referred sources that manufacturers specify on datasheets. It then uses the model to calculate the output noise of a real circuit and to explain how to select an amplifier for a given source impedance.

1. How many ports does an op-amp have?

An op-amp is generally a 5-terminal device (V+, V−, VSS, VDD, VOUT). Each terminal forms a port with respect to ground, so in principle noise can be fed in through all of them, including the power rails. For this analysis the PSRR is assumed infinite, so noise leaking through the supplies is ignored. That brings the port count down to three.

An inverting amplifier can be treated as a 2-port (input referenced to ground, and output), but other applications, such as a difference amplifier, need independent inputs at both terminals. In the general case the op-amp must be analysed as a 3-port device, so we can no longer represent all its noise with just a single input voltage source and a parallel current source.

2. The standard noise model

The standard op-amp noise model therefore uses three noise sources around an otherwise noiseless op-amp:

  • One voltage noise source v̄n in series with either input (conventionally the non-inverting one). It represents the differential input-referred voltage noise.
  • One current noise source into the inverting input īn−. Its effect is a voltage created when this current flows through the source impedance (or whatever impedance) seen looking out of the inverting terminal.
  • One current noise source into the non-inverting input īn+, likewise.
Fig. 1: The standard input-referred noise model of an op-amp (redrawn from the lecture slides)

Why two current sources but only one voltage source? Each input can see a different source impedance, so each needs its own current noise source to create its own voltage. The op-amp, however, works in differential mode, amplifying (V+ − V−), so even separate voltage noise sources at the two terminals would act, once transferred to the output, as a single one.

Datasheets typically list a single input current noise value in even though the model has two sources. By symmetry of the underlying differential-pair input stage, īn+ and īn− have equal magnitudes (unless the datasheet gives separate values).

3. Where the numbers come from: the datasheet

An op-amp is a complex device with many internal resistors, capacitors and BJTs/MOSFETs, each of which can generate thermal, shot and flicker noise. For example, a BJT-based op-amp has two independent bias currents flowing into the two input BJTs, and that alone generates shot noise at the input. Because modelling all of this is impractical, we use the input-referred voltage and current noise values measured or calculated by the manufacturer.

These are specified as a curve (e.g. voltage noise density versus frequency, which rises at low frequency because of 1/f noise) and/or as typical values at specific frequencies; in the TLV2772 datasheet example used in the lecture the current noise is given only as a single value. The input-referred sources are usually assumed to be uncorrelated. This is a good approximation for a simple input differential pair, but in op-amps with input bias-current cancellation the two input current noises can be significantly correlated.

4. Worked example: noise of an inverting amplifier

The intrinsic sources are only part of the total: the external biasing and gain resistors add their own thermal noise, and the current noise terms create extra voltage noise as they flow through those resistors. (The lecture points to TI application note SLVA043B for a step-by-step treatment.)

Problem. An inverting op-amp amplifier has a signal source of impedance RS feeding input resistor R1, with feedback resistor Rf. Derive the total output noise.

Set-up. Replace the op-amp with its input-referred noise model and add a thermal noise source to each resistor. The signal source is grounded for the noise calculation (superposition). Two gains matter:

Noise entering the inverting path sees GI = −RfRS+R1.
Noise entering the non-inverting terminal sees GN = 1 + RfRS+R1.

Note that both depend on the source impedance, so the effective gain can change significantly if RS is large.

External resistors. The thermal noise of RS and R1 is in series with the inverting path, so each is amplified by GI; the thermal noise of Rf is felt directly at the output:

v̄nout,ext2 = (RfRS+R1)2 (v̄nRS2 + v̄nR12) + v̄nRf2

Intrinsic sources. The voltage noise v̄n sits at the non-inverting terminal and is amplified by GN. The current noise īn−: because of negative feedback the inverting and non-inverting inputs are a virtual short, so no current flows through (RS+R1) and all of it flows through Rf. The current noise īn+, on the other hand, sees no resistance on the non-inverting leg and so has no effect at the output (if there were a resistor there, it would).

v̄nout,int2 = GN2 v̄n2 + Rf2 īn−2

Total. All the output noise sources are added, and with all resistors at the same temperature the thermal terms combine:

v̄nout2Δf = 4kBT Rf GN + GN2 v̄n2 + Rf2 īn−2

Here v̄n2 and īn−2 are the datasheet spectral densities (V2/Hz and A2/Hz), which is how they enter the Δf expressions above.

Referring the intrinsic noise back to the input (dividing by GI2) gives a quantity that makes the effect of source impedance explicit:

v̄nout,int−ir2 = v̄n2  (RS+R1+RfRf)2 + īn−2 (RS+R1)2

The second term grows with the square of the source resistance: the SNR drops as RS increases.

5. The impact of source impedance

The term above points to a general rule. Plotting the total amplifier input-referred noise density against source resistance shows three regimes:

Fig. 2: Input-referred noise density versus source resistance, for an illustrative op-amp with en = 5 nV/√Hz and in = 0.5 pA/√Hz at 300 K. The three regimes follow the lecture; the values are illustrative, not taken from a specific datasheet.
  • Low RS: the intrinsic voltage noise (en2) dominates. The intrinsic current noise is “downscaled” (it flows through a small resistance). Pick a low-en (voltage-noise-optimised) amplifier.
  • Intermediate RS, en24kBT < RS < 4kBTin2: the Johnson noise of RS itself dominates. The amplifier is already good enough; no amplifier choice can remove this noise floor.
  • High RS: the intrinsic current noise flowing through RS is scaled up in proportion to RS (inRS), whereas the source’s thermal noise voltage grows only as RS. Pick a low-in amplifier (typically MOSFET- or JFET-input) to push the crossover to very high RS.

6. Choosing the right amplifier

The lecture’s general noise guidance for component selection:

  • A “low-noise” op-amp is not automatically low-noise in every application. Low input-referred voltage and current noise values are independent of the source, but how they transfer to the output does depend on the source impedance.
  • A low-current-noise op-amp only helps when the signal source’s impedance is high (because the amplifier’s low-current-noise advantage would otherwise be buried). If instead the source already has a low impedance, a low-current-noise part may not help at all, because the thermal noise of the external resistors or the op-amp’s intrinsic voltage noise dominates instead.
  • Even a perfect amplifier cannot remove the source’s own thermal noise (spectral density 4kBTRS); the thermal noise of external components also sets a floor.
  • Source impedance also modifies the gain of the amplifier, as the expressions for GI and GN show.
  • Different amplifiers are best at different source impedances: the lecture compares noise-versus-frequency curves for op-amps such as the 741, OP07, OP27 and others at RS = 100 Ω, 10 kΩ and 1 MΩ (Analog Devices data).

7. Homework and take-homes

Homework (from the lecture). A sensor is modelled as an ideal voltage source vS (VS,RMS = 25 µV) with source resistance RS = 1 kΩ, driving a non-inverting amplifier with R1 = 1 kΩ, RF = 10 kΩ and CF = 1 nF. The op-amp has en = 10 nV/√Hz and in = 0.1 pA/√Hz (white; capacitors noiseless; T = 300 K; all noise sources uncorrelated). Tasks include: the transfer function, DC gain and corner frequency; the effective noise bandwidth; the SNR of the source and of the output in dB; drawing and referring every noise source to the input; the input-referred noise and noise figure; which source dominates; and finally repeating the analysis for a 100 kΩ source (e.g. a dry ECG electrode). Does the noise figure get better or worse, and why do the SNR and noise-figure answers point in different directions?

Important take-homes:

  • Op-amps are multi-port devices with many linear and non-linear components inside. We simplify the noise model to two input current noise sources and one voltage noise source.
  • External resistors added to an op-amp add their own thermal noise on top of the intrinsic noise.
  • Choosing a low-noise amplifier means considering the source impedance: low voltage noise does not help when the source impedance is high (there, low current noise is what matters).
  • Despite choosing a low-noise amplifier, the source’s own thermal noise (4kBTRS) and that of external components will still set a noise floor that cannot be removed by swapping amplifiers.
  • The source impedance can also modify the gain of an amplifier.
